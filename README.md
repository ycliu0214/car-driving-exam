# 汽車駕照線上模擬考

**題庫整理日期：民國 115 年 11 月 19 日（2026-11-19）**

本專案使用交通部公路局的汽車筆試題庫與危險感知影片題庫，收錄 **1,090 題靜態題**和 **10 題影片題**。

每回隨機抽出 50 題，先作答 5 題影片題，再作答 45 題靜態題。同一回內題目不重複，選項維持原順序。每題 2 分，交卷後可查看錯題、未作答題及正確選項。

## 發布到 GitHub Pages

1. 解壓縮專案 ZIP，將解壓後的所有檔案與 `assets/` 資料夾上傳到 GitHub 儲存庫根目錄。確認在儲存庫的 **Code** 首頁就能看到 `index.html`。使用 GitHub 網頁版時，圖片可分批上傳，每張圖都要保留在 `assets/` 下。
2. 開啟儲存庫的 **Settings → Pages**。在 **Source** 選擇 **Deploy from a branch**，分支選 **main**，資料夾選 **/(root)**，再按 **Save**。
3. 等部署完成後，回到 **Settings → Pages**，按 **Visit site** 即可開啟模擬考。網站網址通常是 `https://你的帳號.github.io/儲存庫名稱/`。
4. 若要讓訪客從儲存庫首頁直接進入模擬考，回到 **Code** 頁面，點右側 **About** 旁的齒輪，將網站網址填入 **Website** 並儲存。

也可以在解壓後直接用瀏覽器開啟 `index.html` 試用。網站使用相對路徑，無需安裝套件或啟動後端。

## 影片播放

影片題會在頁面內嵌公路局的分享頁，也提供另開原始影片的連結。播放速度與能否內嵌，取決於來源主機的連線與設定。專案透過網址載入影片，GitHub 儲存庫只需保存影片連結。

若手邊已有對應影片，可在該題下方選擇「使用已下載的影片」，直接在目前的瀏覽器播放。[公路局完整影片下載頁](https://reurl.cc/zQj3Ge)

如需改用可供網站發布的 MP4，可將影片放入 `videos/`，並在 `video-bank.js` 的對應題目加入 `"video": "videos/202601.mp4"`。網站會優先使用原生播放器。設定時請依影片編號核對檔案。

## 題庫更新

目前採手動更新。題庫改版後，可更新下列對應檔案，再提交到 GitHub Pages 使用的分支。

- `static-bank.js`：靜態題的題幹、選項和答案。
- `assets/`：靜態題使用的圖示。
- `video-bank.js`：影片題的題幹、選項、答案、影片編號和網址。

`answer` 從 `0` 起算，第一個選項為 `0`。更新時請核對題號、選項順序、答案，以及圖片和影片的對應關係。若日後加入 GitHub Actions，可排程檢查官方 PDF 是否變更，經轉換和驗證後建立 PR，再由維護者確認合併。
